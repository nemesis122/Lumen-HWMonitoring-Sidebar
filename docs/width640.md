# Width up to 640 px

Lumen 4.5.2 extends **Settings → Placement → Width** to **240–640
logical pixels per column**, in steps of 10. Existing width settings remain valid;
move the slider to 640 to use the new maximum.

The same range applies to **Widget width** in horizontal mode. Saved profiles
retain widths above 440 when loaded again. Several columns can share the monitor;
the actual sidebar window is capped at its monitor's available working width.
Full-screen mode still uses the available monitor width.

Five additional selectable designs use native live sensor widgets over clean
case backgrounds: AMD Edition, NVIDIA Edition, Intel Edition, Case Studio and
Case Command Center. They use the actual detected hardware names, including
other GPU manufacturers. Colour and typeface overrides continue to apply.

Select a design in Widgets. For the wide Command Center, enable Placement →
Whole screen. It also works as a sidebar. One to six columns, register assignment,
selected sensors and density remain configurable. Automatic density fits the
work area; Comfortable and Compact retain their existing scrolling behaviour.
