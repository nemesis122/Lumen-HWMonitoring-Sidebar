# Lumen 4.5.4 – Twelve Dark AIO designs

## What's new

- Titanium Rack, Neon Backplate and Airflow Map are each available in four independently selectable layouts: Original, A, B and C.
- A groups load and temperature. B places the artwork in a top strip and aligns the main values on the right. C uses a continuous illustration column.
- Airflow Map's illustration fills the height of its panel. Drive cards show capacity and transfer rates, with a capacity bar. The new layouts use numeric core readouts.
- The layouts use live sensors and the existing settings for colours, fonts, opacity, sizing and sensor visibility.

## Auf Deutsch

Titanium Rack, Neon Backplate und Airflow Map gibt es jeweils als Original, A, B und C. Alle zwölf Designs sind einzeln auswählbar. Die portable Windows-x64-EXE lässt sich neben der bisherigen `lumen-settings.json` starten.
