# Lumen 1.8.0 – new settings window

- Wider settings window (940 px) with topics on the left: Appearance, Layout, Widgets, Position, Readings, Weather and clocks, Power and ping, System. One topic at a time, no long scrolling.
- Register names: boxes below the label, three per line.
- Widget list shows where each widget lands (register, column, style) without opening it.
