# Lumen 1.6.0

- **Up to six columns.** Free widgets are spread so all columns come out about equally tall; the column holding the first widget comes first. Each widget can still be pinned to a column.
- **Registers:** up to six pages, shown as 1 2 3 … in the top bar. Each widget is placed on one of them (Customise ▾ → Register). Switch by click or with the mouse wheel over the top bar.
- **Whole screen:** the sidebar covers the entire monitor up to the taskbar and the columns share its width – a full hardware dashboard.
