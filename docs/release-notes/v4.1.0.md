# Lumen 4.1.0 – 60 Designs, Clear Sensors

This release combines all sidebar improvements with **15 new designs**, bringing the total to **60 selectable designs**. Designs work globally, per register and per widget, on the left, right, top or bottom of the desktop.

## Fifteen new designs

Meridian, Strata, Vector, Orbit, Lucent, Circuit, Panorama, Terminal, Thermal, Mosaic Pro, Ribbon Flow, Split Lens, Aperture, Pixel Deck and Horizon Sync. Dark, light and horizontal previews are included in the screenshots download and [design gallery](../style-gallery.md).

## Complete sensor selection in every design

- All selected hardware readings can be displayed, including optional drive activity, capacity, power-on hours/count and remaining life where the hardware reports them.
- Supplemental readings use the selected design's native bars, segments, tiles, capsules, gradients or typography.
- Missing measurements remain unavailable; no values are invented. Device IDs keep readings attached to the correct hardware.
- Recommended selections are shared across designs. CPU histories and core bars, GPU memory junction, memory peak, advanced drive details and network IP/peak/use values are optional. Drives **Used in %** is off by default; memory Used remains enabled.
- New installations start with Standard. Saved design choices, placement and individual sensor selections remain configurable and persist after restart. World clocks, weather and calendar defaults are unchanged.

## Drives: consistent and compact

- **C: first** is the default. Choose C: first, drive-letter order or detection order under **Widgets → Drives → Customise → Drive order**. The saved order applies to titles, temperatures and transfer values in all 60 designs.
- Model names have one line per drive. Long names are shortened with full names in the tooltip; hardware-name visibility switches apply immediately.
- No Hottest label: temperatures are identified directly by the drive, such as C: · Temp and G: · Temp.
- Temperatures sit side by side in the 15 new designs. Clean Dark, Compact Pro, Performance View and Pure Bar/Number/Segments use large native main-value digits too.
- Dial, Double Ring, Thermostat, Purple dashboard and Sci-Fi use design-appropriate large gauges. Numbers are centred independently of the unit; History Graph has actual per-drive temperature history.
- Read and write appear once per drive, side by side, always below the remaining selected drive readings. Graph variants retain their intended native visuals; Double Ring uses compact transfer numbers below the device gauges.
- Labels, tracks and value columns align; changing digits, units and brief sensor gaps do not cause the widget to jump.

## Fixes

- Fixed the infinite layout loop when changing designs with automatic fitting and hardware names enabled.
- Hardware names are integrated into widget headings while respecting custom names and visibility settings.
- Fixed duplicate upload values in History Graph and corrected CPU/GPU load bindings.
- Fixed stale sensor identities after changing drive order and prevented the °C unit from being interpreted as drive C:.

## Validation

3,799 automated tests and 2,163 extended regression cases passed locally, including 18,105 regression assertions. Tests cover sensor selection, saved settings, multiple simulated hardware configurations, all 60 designs and layout stability. These checks do not claim live validation on every physical device; sensor availability depends on hardware, drivers, permissions and source.
