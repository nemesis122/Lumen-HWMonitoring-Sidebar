# Lumen 1.3.0 – Monitoring HW Sidebar

Portable Windows x64 EXE, .NET included. Start it as administrator for CPU and mainboard temperatures.

- **Two sensor libraries in one EXE:** LibreHardwareMonitor 0.9.6 (with PawnIO) plus a driverless Open Hardware Monitor build for GPUs (NVIDIA/AMD vendor APIs) and drives (SMART). The second only fills gaps and adds hardware only it can see.
- **Fallbacks:** more CPU temperature names (Intel, AMD Zen 1–5), mainboard CPU probe, CPU load from Windows, Vcore from the mainboard, fans from external fan controllers.
- **Settings → System → Show all sensors:** every sensor both libraries found, with Copy and Save.
- Hardware names always visible (switchable), also in Ring and Minimal styles.
- Two columns, three styles per widget (Standard, Ring, Minimal), new widgets: ping, power and cost, data usage, storage space, now playing, system, world clocks, calendar, notes.
- Six languages: German, English, French, Italian, Spanish, Portuguese.
