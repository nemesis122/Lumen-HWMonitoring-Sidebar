# Lumen 1.9.2

- Bar at the top or bottom: Rows (1–6) one below the other, like columns at the side. Each row is as tall as the row height, the bar grows away from its edge, widgets fill the rows in order and can be pinned to a row.
- Layout page for the bar: rows, registers, whole width (off: as wide as the widgets, centred), row height, density, widget width.
