# Lumen 1.6.1

Sensor fixes that apply to all hardware:

- **CPU clock:** uses the real per-core clocks ("Cores (Average)" on AMD, the average of the core clocks elsewhere) and no longer mixes in the much lower "effective" clocks.
- **Intel CPUs:** per-core clocks and loads are now found under Intel's names ("CPU Core #1") and on hybrid CPUs ("P-Core #1", "E-Core #1"), not only AMD's ("Core #1").
- **Drive temperatures:** "Warning/Critical Temperature" are a drive's limits, not readings, and are never shown.
- Hardware names are trimmed; the sensor list now shows each device's identifier and the drive letters matched to it.
