# Lumen 1.9.0 – bars, colours, styles

- Screen edge Top or Bottom: Lumen becomes a bar across the whole width with the widgets side by side; adjustable bar height, can reserve space like the taskbar.
- Three new widget styles: Bar (big value with a thick bar), Graph (history filling the card), Tile (half width, large number; two share a line like rings).
- Nine backgrounds: Graphite, Black (OLED), Midnight blue, Deep sea, Forest, Aubergine, Burgundy, Mocha, Slate.
- Fourteen accent colours instead of five: Cyan, Teal, Lime, Gold, Red, Rose, Magenta, Indigo and Silver added.
