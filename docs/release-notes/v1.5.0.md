# Lumen 1.5.0

- **FPS widget (games):** frames per second of the app in the foreground, 1 % low over ten seconds, frame time and a history chart. Measured with PresentMon 2.3.1 (Intel, MIT licence), which is bundled and only runs while the widget is shown. Needs administrator rights.
- **Drive letters:** drives show their letters ("970 EVO Plus 2TB · C:"), so identical models can be told apart.
- **Own names:** Settings → Names lists every fan and temperature probe; give each your own name or switch it off.
- **Fan names** no longer get cut off ("Chipset Fan" → "Chipset"), and all fan bars start at the same place.
- **Shorter hardware names:** trademarks and filler words are removed ("Intel Ethernet X520-2").
- **Implausible readings** (mainboard probes below 22 °C or above 115 °C) are left out.
- **Click-through** (Settings → Position): clicks go to the windows behind the sidebar; open the settings from the tray icon.
