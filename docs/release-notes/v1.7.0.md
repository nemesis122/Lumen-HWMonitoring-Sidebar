# Lumen 1.7.0 – broader hardware support

- One shared set of sensor rules for LibreHardwareMonitor and Open Hardware Monitor, tested against a real
  Ryzen 9 5900X / RTX 3080 report and typical Intel hybrid, first-gen Ryzen, laptop, Intel Arc and AMD layouts.
- CPU: Tdie preferred over Tctl on Ryzen 1000/2000 (no 20 °C offset), Intel P/E-core clocks and voltages,
  load from the cores when "CPU Total" is missing, ACPI thermal zone as a last resort on laptops without a driver.
- CPU fan: CPU header, else the AIO/pump, else the first turning fan; glitch readings (65535 rpm) ignored.
- Graphics: Intel Arc load/power ("Render/Compute", "GPU Total"), integrated graphics show shared memory as VRAM,
  multi-fan cards show the fastest fan.
- Mainboard: VRM MOS / VSoC MOS, PCH / Southbridge, System #1 and water temperatures (new "Coolant" reading).
- Fans: readable names in all languages ("System Fan #1" → "System 1", "Chassis Fan #2" → "Gehäuse 2",
  "System Fan #5 / Pump" → "Pumpe 5"), duplicates from two chips shown once.
- Network: VPN, Hyper-V, VMware and other virtual adapters are skipped unless they carry the only route.
- Drives without any reading (card readers) are hidden.
