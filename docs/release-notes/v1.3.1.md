# Lumen 1.3.1

- **Docking:** switching between one and two columns (or changing the width) keeps the sidebar flush with its screen edge; no more detour via "Always on top".
- **Two columns with "Automatic":** widgets are split by their real heights so both columns come out equally tall, and any remaining height goes into larger charts and the cards themselves – no empty gaps.
- With very few widgets everything grows slightly.

Includes everything from 1.3.0 (LibreHardwareMonitor + Open Hardware Monitor, sensor list, new widgets).
