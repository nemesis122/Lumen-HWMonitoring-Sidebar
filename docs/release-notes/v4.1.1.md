# Lumen 4.1.1 – Clear Network Values

This maintenance release fixes repeated network readings while keeping all 60 designs and the features introduced in [4.1.0](v4.1.0.md).

## Fixes

- **Evolution and Dial:** download and upload now have explicit sensor identities. The supplemental sensor list no longer repeats the native large values, including when both directions have equal or zero rates.
- **Capsule:** removed the additional upload caption below the hardware name. The hardware heading now spans the available width above the rates instead of being squeezed into a narrow column.
- Network duplicate checks now use sensor identity across **all 60 designs**, so two different counters may legitimately have the same number without hiding a real duplicate.
- Individual sensor visibility remains configurable. Saved sensor selections, designs and placement settings are retained.

## Validation

- **3,802 tests passed**, with no failures or skipped tests.
- **2,163 extended layout/data cases passed**, comprising **18,105 assertions**.
- Evolution, Dial and Capsule network previews were rendered with demo data and visually checked.
- The test suite covers sensor selections, hardware names, drive ordering, persistence, design changes, horizontal and vertical layouts, and simulated hardware configurations. Simulated configurations do not replace physical testing on every device or live external-service testing.
