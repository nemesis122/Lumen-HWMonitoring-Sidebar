# Lumen 4.0.3 – Readable and Steady

Nine new designs, clearer horizontal layouts and stable readings for the hardware sidebar.

## New designs

- Pure and Pure Widgets.
- Clean Dark, Compact Pro and Performance View.
- Pure Bar, Pure Number and Pure Segments: three alternatives to the small load ring.
- Pure Widgets Right: CPU/GPU graphics on the left, additional readings on the right.

All 45 designs remain selectable globally, per register and per widget. The design picker uses four columns with readable, wrapping names.

## Layout fixes

- Horizontal bars bound the size of square graphics so rings no longer force the readings to shrink excessively.
- Horizontal cards use compact charts, sensible spacing and the largest fitting scale after text reflow.
- Pure readings reserve numeric width; transitions such as 9 → 100 no longer move the unit or load label.
- Network 2-min peak keeps its row even when it matches the download rate.

## Integrated graphics

The optional integrated-GPU readings are configured under **Settings → Widgets → Processor → Customise → Sensor values → Integrated graphics**. The option is off by default for new settings. Existing saved choices are preserved.
